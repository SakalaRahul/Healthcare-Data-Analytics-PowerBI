Healthcare Data Analytics & Performance DashboardAn end-to-end enterprise Business Intelligence (BI) and Data Analytics project modeling hospital operations, patient attendance patterns, departmental performance, waiting time bottlenecks, and revenue generation across 12,000+ patient appointment records.📌 Executive Summary & Business ProblemModern healthcare institutions face significant operational challenges, including high patient no-show rates, prolonged waiting times in specialized departments, and uneven resource utilization among doctors. Hospital administrators require centralized, data-driven visibility to optimize scheduling, reduce patient wait times, and maximize revenue without compromising care quality.This project delivers a comprehensive 4-page Power BI executive dashboard backed by a robust SQL relational database and an automated Power Query ETL pipeline to transform raw operational data into actionable C-suite insights.🏗️ Architecture & Data Modeling (Star Schema)To ensure high query performance and efficient DAX calculations, the project implements a Star Schema architecture centered around a core fact table connected to four dimension tables:                  +-------------------+

FactAppointments (12,000+ rows): Granular transactional records of hospital visits, statuses, fees, durations, and waiting times.DimPatients (2,200+ rows): Patient demographic details (Age, Gender, City, Registration Date).DimDoctors (48 rows): Physician metadata, experience years, department mapping, and standard consultation fees.DimDepartments (10 rows): Medical specialty classifications (Cardiology, Orthopedics, Pediatrics, Oncology, etc.).DimDate (1,461 rows): Comprehensive calendar table spanning 2022–2025 supporting time-intelligence calculations.🛠️ End-to-End Implementation Process1. Data Generation & Anomaly IntroductionSynthetic enterprise datasets were generated using Python (pandas, numpy) to replicate real-world healthcare scenarios while maintaining strict privacy compliance (zero real patient PHI):Introduced deliberate raw data quality issues (duplicate appointment IDs, negative waiting time outliers, messy gender casing like 'M', 'female', and null city values) to demonstrate ETL cleaning capabilities.2. ETL & Data Cleansing (Power Query M)An automated transformation pipeline was built in Power Query:Removed duplicate transaction keys using Table.Distinct.Standardized text casing for appointment statuses (Completed, Cancelled, No-Show) and normalized gender fields.Replaced negative waiting time anomalies (< 0) with 0 and suppressed consultation duration outliers.3. Relational Database & SQL AnalyticsCreated relational tables with strict Primary/Foreign Key constraints (sql/02_create_tables.sql) and wrote production analytical queries (sql/04_analytical_queries.sql) and views (sql/05_create_views.sql) to calculate KPIs directly in SQL Server / MySQL.4. Advanced DAX CalculationsDeveloped 21+ measures in Power BI (dax/measures.dax), including:Core Volumes: Total Appointments, Completed Appointments, No-Show AppointmentsRates & Ratios: Completion Rate %, No-Show Rate %, Waiting Time SLA % ($\le 30$ mins target)Financial Intelligence: Total Revenue, MoM Revenue Growth %, YTD RevenueAdvanced Scoring: Custom Doctor Performance Score combining completion rates and SLA adherence.📊 Dashboard Pages & Visual DesignThe dashboard is structured into four targeted reporting pages following professional corporate UI/UX guidelines:Page 1: Executive
